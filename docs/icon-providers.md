# Icon Providers

SinceMenu resolves item icons through provider prefixes.

- `minecraft`
  - Plugin: Bukkit or Paper
  - Example: `minecraft:diamond_sword`

- `mmoitems`
  - Plugin: MMOItems
  - Example: `mmoitems:SWORD:CUTLASS`

- `itemsadder`
  - Plugin: ItemsAdder
  - Example: `itemsadder:iasurvival:ruby`

- `nexo`
  - Plugin: Nexo
  - Example: `nexo:ruby_sword`

- `mythiccrucible`
  - Plugin: MythicCrucible
  - Example: `mythiccrucible:my_crucible_itemid`

Third-party providers are optional. If a provider fails, SinceMenu falls back to the configured `fallback-icon`.
